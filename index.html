Matching machine types
Matches meet or exceed both entered capacities on one VM. Custom N4/N4D sizes follow Google’s allowed vCPU steps and 256 MiB memory increments; an exact capacity match is flagged. Results are sorted by the fewest extra vCPUs, then the least extra memory. Hourly and monthly estimates use on-demand Linux compute and Balanced boot and optional attached block volume; taxes, private/inter-region traffic, load balancer and NAT processing, snapshots, and discounts are excluded. Google Cloud custom rates use published per-vCPU and per-GiB Iowa rates, adjusted by the corresponding C4 or C4D regional price factor. Predefined VM rates use published 32-vCPU references with a linear adjustment for other sizes. Oracle compute and storage use global USD list rates; egress varies by origin geography. Monthly estimates use 730 hours; storage and internet egress monthly rates are divided by 730 hours. Egress is an illustrative Premium Tier estimate for the selected destination. OCI egress rate class follows the selected region’s geography; actual source and destination rates can differ. Check current provider quotes before purchase.
HOW TO READ THIS

A sizing starting point,
not a benchmark.

Comparable thread counts and memory help narrow the choices. CPU generation, clock behavior, storage, networking, and workload profile can change real throughput.

For the AMD comparison, Oracle lists EPYC 9J45 at 2.7 GHz base and 4.1 GHz maximum boost; Google lists EPYC 9B45 at the same 2.7 GHz base and 4.1 GHz maximum boost, with a 3.5 GHz effective frequency. These published clocks do not establish a per-core performance winner. Oracle shape specifications ↗ · Google CPU platforms ↗

Compute Engine C4D uses AMD EPYC 9B45 (Turin). C4 uses Intel Xeon Platinum 6985P-C (Granite Rapids) at 144 or 288 vCPUs; smaller C4 VMs and 192-vCPU C4 VMs can use Intel Xeon Platinum 8581C (Emerald Rapids) or 6985P-C (Granite Rapids), depending on the CPU platform available and selected. Both offer predefined high CPU, standard, and high memory sizes.

For a Flex-style custom vCPU and memory configuration on public Compute Engine, Google Cloud offers N4 and N4D. C4 and C4D offer predefined sizes. This calculator includes both types. Available machine series vary by region; some locations offer Intel N4/C4 but no AMD N4D/C4D. N4D extended-memory matches need a direct price check because the published VM price table does not show their extended-memory rate.
